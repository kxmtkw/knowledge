## Increasing / Decreasing Functions

> A function that is increasing or decreasing on an interval is said to be `monotonic` on that interval.

## How to Find

1. Find all critical points and points where $f$ shows discontinuity (undefined or jumps).
2. Using these points, divide the domain into intervals.
3. Pick a test point from each interval.
4. Find $f'(x)$ for all those test points.
	1. If $y' > 0$, the function is increasing over that interval.
	2. If $y' < 0$, the function is decreasing over that interval.
	3. If $y' = 0$, the function is constant over that interval.

Follow the model: `PITF` Partition points, Intervals, Test point, First derivative
-> PITFall
