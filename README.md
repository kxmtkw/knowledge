
## Repository of Knowledge

A repository containing random knowledge that I learned at university and also by myself.

This repo contains:
+ CS related knowledge, both from university and self learning.
+ Random puzzles, some of which link to CS in some way.

## Installing

Install by simply cloning the repository as:
```bash
git clone --depth=1 https://github.com/kxmtkw/knowledge.git
```
or by SSH:
```bash
git clone --depth=1 git@github.com:kxmtkw/knowledge.git
```
or just download the zip file for ease.
